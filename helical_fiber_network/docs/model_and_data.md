# 网络和合成数据定义

## 1. 理论层

延用已核对的论文模型：λ=√(r²+(h/2π)²)，r=0.017 m，h=0.005 m，Lf=4.277 m，L=0.2 m，N=8，C=0.012，ω=0.999。

```
Ψ(s) = -abs(sin(π N s/Lf))
ε_b(s) = -C κ r Ψ(s) sin(ωs/λ + φ)
a = κ cosφ; b = κ sinφ; θ = κ L
```

理论矩阵 X 的前两列为展开后的 sin/cos 基，第三列为偏置。神经单位为 strain/(100e-6)。理论层没有可学习几何参数；训练不会同时无约束拟合 C 和 κ。

## 2. CNN 与物理解码器

5 个膨胀卷积层，24 通道，kernel=5，dilation=1/2/4/8/16，SiLU 激活。输入共 6 通道：原应变、初始 OLS 残差、两个理论基、归一化光纤坐标、局部力灵敏度。

共享特征分别进入：

- support 头：tanh 输出 g(s)∈[-1,1]，表示有符号的局部接触形状；不宣称是概率。
- force 头：4*sigmoid 输出 F(s)∈(0,4) N；只有接触支撑区有效，训练标签为 1–3 N。
- shape 头：特征全局均值及与两个基函数的相关池化，MLP 输出对投影系数的小幅修正。

```
ε_contact_hat(s) = g_hat(s) [c(s) F_hat(s) + intercept(s)]
coef_hat = pinv(X) [y - ε_contact_hat] + 0.1 MLP(features)
ε_b_hat = X coef_hat
ε_reconstructed = ε_b_hat + ε_contact_hat
```

这是 CNN 与解析投影融合的网络，形状输出包含固定最小二乘层和可学习修正，不能称为完全不依赖理论的黑盒估计。所有训练分支通过 PyTorch 自动微分联合优化。无 PDE 项，不称为传统 PDE PINN。

损失：5×接触应变 MSE + 2×support MSE + 0.15×力 MSE + 4×系数 MSE + 0.5×重构 MSE。接触与 support 以 1+15|g_true| 加权；力以 |g_true|⁴ 加权，只在真值接触核心监督。形状用 a/b 而不直接回归 φ，避免 ±π 跳变，并自然处理 κ=0。

重构损失不是唯一约束；真值系数、support 和力监督用于限制分解的不唯一性。力头与 support 仍可能互相补偿，尤其是在真实分布外数据上，因此推理同时报告峰值标定力与网络力的差值。

## 3. 三类训练数据

纯弯曲：κ>0、无接触；混合：κ>0、有接触；纯接触：κ=0、有接触。三类均可能包含基线漂移与测量噪声，“纯”指潜在物理分量的标签，不指无噪声。

弯曲样本中 80% 的 κ 均匀取 0.12–1 /m，20% 取 1–4 /m，对应约 1.38–45.84°。φ 均匀覆盖 [-π,π]。这种分布既覆盖参考实测约 100 με 的幅度，也保留较大弯曲样本。

每帧接触包含 1 个簇，25% 概率加入第 2 个簇，簇中心至少间隔约 0.9 m 光纤长度。每簇 1–4 峰，峰距约 0.107 m（一个螺旋周期），位置加入 2 mm 光纤坐标扰动。85% 簇为正峰，15% 为负峰。每峰标签为 1–3 N，正态核宽度 8–17 mm 光纤长度；压力测试改为 5–25 mm。

局部 contact = g(s)[c(s)F(s)+intercept(s)]。c/intercept 按第一段 disk/gap 参数，在每个采样位置计算。相比旧工程用峰中心的标定系数乘整条高斯，此处将标定延伸到局部场，跨区时可能出现跳变，这是为了固定可微解码器所用的建模选择，不是论文推导出的接触连续介质解。

峰间距较大；极小尾部重叠用绝对 support 较大的峰占优，不模拟同位置多个力的可分离叠加。cluster_id 只保留用于以后研究跨圈关联，本网络没有预测物体实例或簇总力。

噪声标准差 0.5–3 με；另加入低频漂移（幅度至 12 με）、二次谐波（至 5.5 με）与小幅弯曲趋势变化。后者作为 nuisance 标注，不伪装成接触真值。压力测试将这些干扰加倍，但不是完整的跨传感器或跨材料域外测试。

## 4. 标签与可辨识性

- 几何、Cscale 和相位零位已知；不能由相同应变唯一同时识别 Cscale 与 κ。
- 零曲率时偏转角不可辨识；评估偏转角只计非零弯曲真值。
- F 是每个光纤局部峰的有效法向载荷。多个峰可能对应同一物体，不能相加宣称总力。
- 力头受合成 1–3 N 标签影响，输出上限为 4 N；超过真实标定范围需重新采集数据。
- 未学习 tangential force、独立扭转、材料参数和非 PCC 三维形状。
- XYZ 来自 PCC 几何映射，是当前段基座坐标，不是已验证的世界坐标。

## 5. 数据隔离和评估

train/val/test/stress 分别使用种子 1102/2102/3102/4102，独立生成场景，不从同一时间序列随机拆帧。训练轮次仅按 validation joint loss 选择。真实两条曲线用于人工参考波形与推理展示，没有角度、位置或力标签，不报告真实精度。

匹配预测峰与真值峰使用带距离门限的匈牙利匹配，光纤坐标容差 20 mm。位置 RMSE 为光纤弧长误差，不是主干轴向或三维定位误差；力和位置 RMSE 只针对匹配峰，必须同时看精确率、召回率和漏检数。无接触帧单独统计误报率。

Tukey 对照使用同一 1536 点测量与原配置，未对其重新调参；网络使用合成标签训练。因此比较说明此生成分布下的行为，不构成网络普遍优于最优理论估计器的证明。
